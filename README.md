# Service-Werkzeugkasten

Werkzeuge für den Lüftungsservice: Volumenstromrechner, Steuerungs-Zugänge, Hygieneinspektion (Vor-Ort-Aufnahme), PDF zusammenfügen, Restmängel/Abnahme und Anlagenaufnahme.

Die Seite besteht aus einer einzigen Datei (`index.html`). Eingetragene Daten werden nur im Browser des jeweiligen Geräts gespeichert, nicht auf GitHub.

**Neue Version hochladen:** Add file → Upload files → neue `index.html` hineinziehen → Commit changes.
